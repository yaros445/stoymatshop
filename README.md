# СтройБаза

Демо-магазин стройматериалов на React, TypeScript, Material UI и Vite. Маршруты настроены отдельной конфигурацией React Router и отрисовывают самостоятельные страницы каталога, калькулятора, профиля, компании, отзывов и доставки. Корневой адрес перенаправляет в каталог.

## Структура приложения

- `src/routes/router.tsx` — вложенные маршруты, общий layout и загрузка страниц по требованию.
- `src/pages/` — самостоятельные страницы приложения.
- `src/components/layout/StoreLayout.tsx` — общая шапка, навигация, корзина и оболочка страниц.
- `src/app/StoreProvider.tsx` — общее состояние каталога, корзины и демо-профиля.
- `src/app/theme.ts` — тема Material UI, согласованная с цветами магазина.

## Запуск

```sh
npm install
npm run dev
```

Для production-сборки выполните `npm run build`.

## Backend API

Отдельный Express + TypeScript backend с Prisma и MySQL находится в [`backend/`](./backend/README.md). См. его README для настройки базы, миграций, тестовых данных и запуска API. Клиент пока не подключён к backend и продолжает использовать демо-данные браузера.

## Демо-возможности

- Регистрация и вход по email и паролю.
- Оформление заказа с контактами, адресом и оплатой при получении.
- История заказов для вошедшего пользователя.

Данные аккаунтов и заказов хранятся только в `localStorage` текущего браузера. Пароль сохраняется в виде PBKDF2-хеша, но авторизация выполняется на клиенте и не является безопасной серверной аутентификацией. Заказы не отправляются продавцу, доставка и оплата не обрабатываются. Не используйте реальные пароли или персональные данные. Для реального магазина необходим backend с защищённой аутентификацией и хранением заказов.
